# Research — arXiv Review Papers

Each paper is a focused review compiled from one or more book chapters, with a **declared
novel delta** beyond the chapter — the thesis, taxonomy, gap-argument, or finding the paper
adds beyond distilling the source. A paper is never a chapter.

One directory per paper: `p1-evaluation/`, `p2-guardrails/`, etc. Each holds the LaTeX
source, figures, and a `DELTA.md` stating the novel contribution before drafting begins.
